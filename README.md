# Electra Study Hub

Interactive study lessons, starting with **Electra**, a circuit analysis course
(units 1A to 6: quantities and units, resistors, Ohm's law, series/KVL,
power, atomic theory, parallel/KCL, series–parallel) with a 3D practice bench.

## Current state

`electra.html` is the latest built version of Electra (October 2026), a single
self-contained file. Open it in any browser; no install needed.

Progress is saved in the browser under `electra.last.v1` and `electra.freelab.v1`.
